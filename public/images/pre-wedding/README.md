# Pre-Wedding Images

This folder currently contains clearly marked temporary replacement images:

- `pre-wedding-01.svg`
- `pre-wedding-02.svg`
- `pre-wedding-03.svg`

Replace these files with the couple's real pre-wedding photos before launch. Keep the filenames or update `lib/wedding-content.ts` with the new image paths, alt text, captions, and display order.

Image guidance:

- Prefer portrait or vertical-crop photos for the gallery.
- Compress images before deployment.
- Keep faces and important details away from the extreme edges.
- Add meaningful Vietnamese alt text for each photo.
